# Project 05 – Titanic Survival Prediction Web App

## Overview
An interactive machine learning web application built using Streamlit. It predicts the likelihood of survival for a Titanic passenger based on their passenger class, gender, age, and ticket fare.

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## Machine Learning Model
- Algorithm: Decision Tree Classifier
- Dataset: Titanic dataset
- Test Accuracy: 77.65%
- Model saved using Joblib

## Features
- Interactive passenger input fields
- Real-time survival prediction
- Estimated survival probability
- Simple and user-friendly interface

## How to Run Locally
Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
